# Velvet Grounds - The Art of Coffee

An ultra-premium, visually stunning, and technically sophisticated coffee shop website built with the vanilla stack. Designed to push the boundaries of UI/UX, this project embodies the aesthetics of Glassmorphism, Bento Grids, and a highly polished dark-mode luxury, reminiscent of Apple's design philosophy.

## ✨ Features

*   **Breathtaking UI/UX:** A unique, non-generic layout with a focus on visual hierarchy and stunning aesthetics.
*   **High-End Animations:** Complex, "framer-motion style" animations implemented with pure Vanilla JavaScript and Tailwind CSS for smooth, engaging interactions.
*   **Glassmorphism & Dark Mode Luxury:** A sophisticated dark theme with transparent, blurred elements that create a sense of depth and elegance.
*   **Bento Grid Layouts:** Modern, modular grid structures for menu and content presentation.
*   **Responsive Design:** Optimized for a seamless experience across all devices.
*   **Vanilla Stack:** Built purely with HTML5, Tailwind CSS (CDN), and Vanilla JavaScript (inline) for maximum performance and minimal overhead.

## 🚀 Technologies Used

*   **Frontend:**
    *   HTML5 (Semantic Structure)
    *   Tailwind CSS (CDN-only for utility-first styling)
    *   Vanilla JavaScript (Inline for dynamic interactions and animations)
*   **Backend:** None (Static Site)
*   **Deployment:** Vercel (configuration included)

## 🛠️ Setup & Local Development

This project is a static site and requires no complex build steps.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/velvet-grounds.git
    cd velvet-grounds
    ```
2.  **Install a simple static server (if you don't have one):**
    ```bash
    npm install -g serve
    ```
3.  **Run the project:**
    ```bash
    serve .
    ```
    This will typically start the server at `http://localhost:5000`.
